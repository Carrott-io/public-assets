# Stamp image library

Versioned, transparent PNG stamp images for Carrott's card builder.

- `manifest.json` is the canonical catalogue index used by the library sync.
- Every image is a square RGBA PNG with a transparent background.
- The library contains one image per icon. Inactive variants are intentionally
  not part of this collection.
- Released versions are immutable. Add a new version directory for a future
  visual refresh instead of replacing assets used by existing cards.
